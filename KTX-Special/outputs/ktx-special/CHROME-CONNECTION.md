# 기존 Chrome 연결 모듈 — 0.2 개발판

2026-11-23 사용자의 기존 Chrome 창을 Windows UI로 직접 조작해 코레일 열차 조회에 성공했습니다. 11월 23일 서울 → 포항, KTX-산천 259번 08:35~10:55의 일반실·특실이 조회 시점에 모두 매진으로 표시됐습니다. 이전 -8003은 별도 내장 브라우저에서 관측됐습니다. 계정 전체나 사용자의 Chrome까지 차단됐다는 근거가 아닙니다.

이 연결 모듈은 **아직 실제 Chrome 확장 설치 후 실행 검증을 하지 않았습니다.** UI 조회 성공과 확장프로그램의 성공은 별개의 결과입니다. 설치 후 첫 상태 전달을 확인해야 합니다. 자동 예약은 구현되지 않았습니다.

## 설치 전 확인할 권한

`chrome-extension/manifest.json`에 선언한 권한은 다음과 같습니다.

- 코레일(www.korail.com) 페이지 접근: 이미 열린 열차 조회 결과를 읽기 위해 필요합니다.
- localhost(127.0.0.1:47831) 접근: 내 PC 앱과 통신하기 위해 필요합니다.
- scripting: 조회 결과 화면에 결과 해석 코드를 주입합니다. 로그인·마이페이지 화면에는 코드를 실행하지 않습니다.
- storage: PC 연결 토큰과 새로고침 설정을 해당 확장프로그램 저장소에 저장합니다.
- alarms: 1분 간격 작업을 예약합니다.
- notifications: PC의 Chrome 알림으로 자리 발견을 알립니다.

cookies 권한, 로그인 비밀번호 읽기, 세션 쿠키 추출·전송, 결제·취소·예약 클릭 코드는 없습니다. 읽은 데이터 중 날짜·구간·열차번호·시각·일반/특실 표시 상태만 내 PC 앱으로 보냅니다.

## 설치 및 연결

1. `Start.cmd`로 PC 앱을 켭니다.
2. Chrome의 확장프로그램 관리 화면(chrome://extensions)을 엽니다.
3. 권한과 코드를 확인한 뒤 본인이 설치를 결정하면 개발자 모드를 켜고 ‘압축해제된 확장프로그램을 로드합니다’를 선택합니다.
4. 이 배포 폴더 안의 **chrome-extension 폴더**를 선택합니다. ZIP 파일 자체를 선택하는 방식이 아닙니다.
5. PC 앱의 ‘기기 연결 → Chrome 연결 코드 만들기’에서 1회용 코드를 만듭니다.
6. Chrome 확장프로그램 팝업에 코드를 입력해 연결합니다.
7. 코레일에서 정확한 날짜·구간·인원으로 열차를 조회하고 결과 탭을 열어 둡니다.
8. PC 앱에도 같은 조건의 여행을 등록하고 감시 요청을 켭니다.
9. 확장프로그램의 ‘지금 상태 전달’을 누릅니다. **정확한 열차·시각·특실 상태가 앱에 도착했는지 먼저 확인**합니다.
10. 결과가 정확하면 확장프로그램에서 1분 간격 새로고침을 켭니다.

확장 설치와 사이트 접근 권한은 사용자 확인 없이 적용하지 않았습니다. 앱에서 Chrome 연결을 해제하면 저장된 토큰은 즉시 무효화됩니다.

## 작동 범위와 중단 조건

- 이미 열어 둔 조회 결과 탭 중 최대 3개를 읽습니다. 등록 여행과 일치하는 결과 탭만 새로고침합니다.
- 로그인 만료, 이용 제한, 결과 화면 해석 실패, PC 연결 실패가 발생하면 자동 새로고침을 끕니다.
- 페이지 새로고침 후 검색 조건이 유지되지 않는 경우에도 일치하는 결과가 없으면 새로고침하지 않습니다. 이 동작은 설치 후 실기기 확인이 필요합니다.
- Chrome을 닫거나 PC가 절전 상태가 되면 작동하지 않습니다. Chrome이 장시간 유휴 상태일 때의 알람 지연도 실기기 확인 대상입니다.
- ‘특실 표시 발견’은 실제 좌석 확보와 다릅니다. 인원 전체 수용·인접 좌석·예약 성공을 보장하지 않으며 예약은 직접 진행해야 합니다.
- 현재 자리 발견 알림은 **PC Chrome 알림과 앱 활동 기록**입니다. 휴대폰 푸시는 별도 HTTPS·기기 등록·실수신 검증이 필요하며 이 모듈에 연결하지 않았습니다.
- 자동 새로고침이 코레일에서 허용되거나 차단되지 않는다고 보장하지 않습니다. 차단을 감지하면 중단하며 기기 식별자 위조·보안 토큰 생성·IP 변경 방식은 사용하지 않습니다.

## 검증 범위

실제 UI에서 관측한 열차 행 문자열을 이용한 해석 검사, 날짜·구간·열차 일치 검사, 오래된 결과 제외, 연결 코드 1회 사용·확장 ID·토큰 검증, 알림 중복 방지, 연결 해제 후 접근 차단을 자동 검사했습니다. Chrome 확장프로그램의 실제 설치·실수신 검증과 자동 예약 검증은 수행하지 않았습니다.
