기존 Selenium(직장) 프로필 연결 도우미 — 이 PC용

기존 Chrome 프로필 경로를 화면에서 확인했습니다: User Data\Profile 1.
Chrome에서 원격 디버깅을 사용자가 켠 상태를 전제로 합니다.
이 실행 환경에서는 연결 주소 파일(DevToolsActivePort) 읽기가 허용 요청 후에도 EPERM으로
막혀서, 이 도우미를 사용자가 일반 권한으로 직접 한 번 실행해야 합니다. 관리자 권한은 요구하지 않습니다.

RunExistingProfile.cmd를 실행합니다. Chrome에서 연결 승인 화면이 나오면 이 도우미의 연결을 확인합니다.
‘Selenium 연결 성공’이 표시되면 창을 열어 둡니다. 종료는 Ctrl+C입니다.

도우미 동작:
- Chrome의 연결 주소 파일 하나만 읽습니다. 쿠키/비밀번호/Local State 파일은 읽지 않습니다.
- 열려 있는 Chrome에 붙습니다. 새 프로필을 만들거나 기존 프로필을 복사하지 않습니다.
- Chrome의 새 연결 서버와 ChromeDriver 사이의 HTTP 탐색 형식 차이를 localhost 어댑터로 연결합니다.
- 어댑터는 127.0.0.1의 임의 포트에만 열며 웹페이지의 Origin이 있는 요청은 거부합니다.
- 표시된 코레일 조회 탭(#ktx-profile1-probe)만 선택합니다.
- 조회 전용 동작만 받습니다. 예약/결제/취소/로그인 버튼 동작은 거부합니다.
- 종료 시 도우미가 만든 ChromeDriver와 연결만 끕니다. 사용자의 Chrome은 닫지 않습니다.
- 실행 상태와 명령/결과는 이 폴더의 .runtime에 저장합니다. 공유하거나 공개 저장소에 올리지 마세요.

설치된 Selenium 4.54.0과 이 작업의 work/selenium-probe 의존성 폴더를 사용합니다.
다른 PC에서 바로 실행하는 배포 패키지가 아닙니다.
